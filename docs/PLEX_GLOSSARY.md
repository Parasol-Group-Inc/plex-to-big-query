# Plex glossary — the part of it we use

Generated by `scripts/distill_glossary.py`. **Do not hand-edit** — re-run it.

Plex's full export is **61,022 entries**. This is the **93** of them that name something this repo actually reads: 0 tables and 93 fields.

Terms are matched on the name, ignoring case and underscores, so `Minimum_Inventory_Quantity` finds Plex's "Minimum Inventory Quantity". Substring matching is deliberately **not** used — "Part" alone would pull in hundreds of entries and bury the useful ones.

A term missing here means one of two things: Plex never defined it, or we invented the name ourselves. Both are worth knowing when someone asks *"where does that come from?"*
